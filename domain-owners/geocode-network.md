
Network geocoding is used to look up visitors' approximate location based on the network address (IP address) of their device. This information is provided only to the visitor's web browser in order to display a default map starting point, and is not tracked within the Emissary server.

To set up a network geocoder , sign in to your Emissary server as a domain owner, navigate to  **Server Settings \> External \> API Keys**.

You'll need to sign up for an account with one of the third-party providers listed below. All include a free tier that will work for small websites without any additional fees.

## Static Geocoder
If your Emissary server is dedicated to a particular geographic region, then you should set up the Static Geocoder, which always returns a fixed point location.  This will always focus your website maps on your chosen coordinates without inspecting the visitor's IP address or looking up their location with an external service provider.
