
Emissary supports many kinds of geographic services. Most third-party providers offer more than one of these services. Domain owners can set up each of these independently, enabling you to mix and match the services and providers that fit your needs best.

In general, no single provider supports every capability. So, you will likely need to set up more than one provider.  Providers like [here.com](https://here.com) and [geoapify.com](https://geoapify.com) provide *most* of these services, so they are a good to try first when getting things set up.

**[Address Search](/geocode-autocomplete)**<br>
Address search provides autocomplete suggestions when entering addresses. Set up this provider if your Emissary app allows users to enter addresses.

**[Address Geocoder](/geocode-address)**<br>
Address geocoders find map coordinates (longitude, latitude) from an address. Set up this provider if your Emissary app displays addresses on a map.

**[Network Geocoder](/geocode-network)**<br>
Network geocoders look up device locations from their network address (IP address). Set up this provider if your Emissary app displays maps relative to visitors' approximate location.

**[Timezone Geocoder](/geocode-timezone)**<br>
Timezone geocoders look up time zones for individual locations.  Set up this provider if your Emissary app tracks events in local time.

**[Map Tiles](/geocode-maptiles)**<br>
Map tile servers provide the images that make up an interactive map.  Set up this provider if your Emissary app displays map images.
