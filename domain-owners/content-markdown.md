Markdown is a simple way to write web page content that  uses simple annotations to create headings, tables, or character styles (like bold and italics).  This makes it easy to write rich-text documents without a lot of fuss.

[Learn Markdown in 60 seconds.](https://commonmark.org/help/) Emissary uses a specific flavor of Markdown called CommonMark, which guarantees the same syntax across many different platforms.
