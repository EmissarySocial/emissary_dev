
Timezone geocoding services look up the local timezone for an address.  This is used to publish events times (like start dates and end dates) in the correct local time. visitors' approximate location based on the network address (IP address) of their device. 

Many timezone geocoders also work as regular address geocoders, so most timezone information can be retrieved from them in a single step.  In this case, then the timezone data from your address geocoder is used without making a separate call to the timezone service.  However, if your preferred address geocoder does not include timezone information, then an additional timezone geocoder can be used as a backup.

To set up a timezone geocoder , sign in to your Emissary server as a domain owner, navigate to  **Server Settings \> External \> API Keys**.

You'll need to sign up for an account with one of the third-party providers listed below. All include a free tier that will work for small websites without any additional fees.
