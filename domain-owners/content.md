Emissary is a full-featured content manager. When you create a website using Emissary, you control the content on all of its web pages.   

Several kinds of content pages are available. These may vary depending on how your server owner has configured your server.

Server owners can also create and install their own customized templates.  So, if you need to create web pages that are different from the ones available, you'll need to run your own server.

If you need additional kinds of web page designs, talk to your server owner about creating and installing custom templates.
